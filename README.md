# Jordan Vorster

Computer Science student at the University of London, based in the Eastern Cape, South Africa.

I build systems end to end: terminal applications, native C++ engines, Rust emulators, and language models trained from scratch. I care about correctness under real conditions — tested code, honest documentation, and infrastructure that can be operated, not just demoed.

### Flagship projects

- [Ubume-CLI](https://github.com/golba98/Ubume-CLI) · a terminal workspace for coding agents — one stateful TUI for Codex, Claude Code, Antigravity, Mistral Vibe and local models ([on npm as `ubume`](https://www.npmjs.com/package/ubume))
- [SyncroEdit](https://github.com/golba98/SyncroEdit) · a production real-time collaborative editor on Cloudflare: Yjs CRDTs over WebSockets, a Durable Object per room, D1 persistence ([live](https://syncroedit.online))
- [LLM-From-Scratch](https://github.com/golba98/LLM-From-Scratch) · an eight-package PyTorch language-model engineering monorepo: tokenization, transformer architecture, data, training, inference and memory
- [hp-prime-emulator](https://github.com/golba98/hp-prime-emulator) · a native Rust emulator for HP Prime PPL: parser, bytecode VM, 12-digit BCD arithmetic, headless graphics, a desktop IDE, and differential testing against real hardware over USB

### Also worth a look

- [IT_Pixel_Forger](https://github.com/golba98/IT_Pixel_Forger) · a C++23 mosaic engine that rebuilds any image as an animated block mosaic, with a Qt 6 GUI and GIF-export CLI
- [HTTP-Server](https://github.com/golba98/HTTP-Server) · an HTTP/1.1 server from scratch in C++23: incremental RFC 9112 parsing, bounded thread pool, fuzzing and sanitizers
- [MyGUI](https://github.com/golba98/MyGUI) · a small C++20 GUI library on GLFW, OpenGL 3.3 and FreeType
- [Game_Development](https://github.com/golba98/Game_Development) · a top-down procedural RPG engine in JavaScript and p5.js
